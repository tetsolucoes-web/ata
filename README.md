# Ata de Atendimento – SESI CE-442

Aplicativo (PWA) para registrar atendimentos: grava a reunião, transcreve, redige a ata e envia para a automação da escola.

- Acesso por código pessoal (PIN).
- Nenhum dado de estudante fica neste repositório: a relação de estudantes chega ao aparelho somente após o login.
- O áudio fica apenas no aparelho e é apagado assim que a transcrição é concluída.
